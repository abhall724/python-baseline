# Repository Cleanup Prompt

Use with the `cleanup` skill.

You are cleaning a repository that may contain excessive boilerplate and
abstractions generated by a previous LLM coding agent.

Do not modify anything during the first pass.

## First Pass

Inspect the repository and produce an architectural cleanup report.

Identify:

- unnecessary abstractions
- one-implementation interfaces/protocols
- one-function classes
- pass-through services
- pass-through repositories
- one-product factories
- unnecessary wrappers
- duplicate models/DTOs
- unnecessary mappers
- generic utility/helper modules
- duplicate configuration
- unused files
- generated files incorrectly treated as source
- unnecessary dependencies

For every candidate provide:

- location
- purpose
- consumers
- concrete value provided
- why it may be unnecessary
- proposed simplification
- confidence: HIGH / MEDIUM / LOW

Classify each candidate:

- KEEP
- COLLAPSE
- MERGE
- DELETE
- DEFER

Do not make changes until the report is complete.

## Second Pass

Challenge your own report.

For every proposed removal, ask:

> What concrete value might this abstraction provide?

Identify false positives and move uncertain items to DEFER.

## Third Pass

Implement only HIGH-confidence DELETE candidates.

Run relevant tests and inspect the diff.

Then handle HIGH-confidence COLLAPSE candidates in small logical batches.

Do not perform broad refactoring.

## Final

Inspect:

- git status
- complete git diff
- tests
- lint/format/type validation
- deleted symbol references
- orphaned files
- generated artifacts

Report:

- removed
- collapsed
- merged
- kept
- deferred
- validation commands and results
- remaining concerns
